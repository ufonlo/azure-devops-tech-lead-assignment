# Pull request review

## Status

Blocked: the supplied assignment document refers to a repository/PR but contains no usable URL. Request the missing link rather than inventing a review.

## Review method once supplied

1. Read the stated goal and changed-file scope.
2. Trace trust boundaries, permissions, secret flow and state behavior.
3. Check correctness, idempotency, failure handling and rollback.
4. Reproduce relevant validation locally where safe.
5. Separate blocking findings from suggestions and questions.

## Review format

| Severity | File/line | Finding | Impact | Suggested change |
|---|---|---|---|---|
| Blocker / Major / Minor | pending | pending | pending | pending |
